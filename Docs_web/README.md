# LST Docs Web

Docusaurus 기반 사용자 문서 사이트입니다.

## 로컬 실행

```bash
npm install
npm run start
```

## 빌드

```bash
npm run build
```

## Vercel 배포

- Project Root Directory: `Docs_web`
- Build Command: `npm run build`
- Output Directory: `build`
- Install Command: `npm install`

## 문서 정책

공개 사용자 문서만 포함합니다. `docs/LST-PJ_V3/planning` 및 `docs/LST-PJ_V3/sensitive-draft` 문서는 이 사이트에 직접 포함하지 않습니다.
