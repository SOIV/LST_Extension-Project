# LST Project 문서

Live Stream Translator(이하 'LST') Project는 실시간 자막, 번역, 커뮤니티 자막 제작과 공유를 지원하는 사용자 도구와 플랫폼입니다.

## 문서 구성

- **Beta 가이드**: 현재 베타 버전의 설치, 설정, 사용법을 다룹니다.
- **Apps**: Chrome 확장 프로그램과 데스크탑 앱 사용 방법을 다룹니다.
- **Platform**: 커뮤니티 자막 플랫폼, 자막 제작, 업로드, 승인 흐름을 다룹니다.
