# 문제 해결

## START LISTENING이 동작하지 않음

- 현재 탭이 지원 대상 페이지인지 확인합니다.
- OpenAI API 키가 입력되어 있는지 확인합니다.
- 탭 오디오 캡처 권한 요청이 차단되지 않았는지 확인합니다.

## 마이크 인식이 불안정함

- Chrome 마이크 권한을 확인합니다.
- 원본 언어가 `자동`이면 브라우저 언어로 인식될 수 있습니다.
- Web Speech API는 브라우저와 OS 환경에 따라 결과가 달라질 수 있습니다.
- Web Speech API(또는 웹 브라우저의 마이크)는 OS에 설정된 입력의 기본값으로 동작하기에 스테레오 믹스(이하 '스믹')이 아닐 경우 자신의 마이크로 동작합니다.

## 번역이 표시되지 않음

- 목표 언어가 원본 언어와 같은지 확인합니다.
- 선택한 번역 엔진에 필요한 API 키 또는 URL이 입력되어 있는지 확인합니다.
- Google 기본 번역 엔진으로 바꿔 동작 여부를 확인합니다.

## Realtime 결과가 끊기거나 중복됨

Realtime API의 VAD와 중간 번역 표시가 조정 중입니다. 안정성이 필요하면 OpenAI Transcription API를 사용해 주세요.
