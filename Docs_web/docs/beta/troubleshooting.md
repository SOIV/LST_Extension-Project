# 문제 해결

## 커뮤니티 자막이 표시되지 않음

- 배지가 `CC`(초록)인지 확인합니다. 회색이면 해당 영상에 자막이 없거나 아직 로딩 중입니다.
- 팝업 **커뮤니티** 탭에서 커뮤니티 자막이 켜져 있는지 확인합니다.
- 선택한 언어로 자막이 제공되는지 확인합니다. 언어를 `자동`으로 바꿔보세요.
- YouTube SPA 이동(재생목록 등) 후 자막이 다시 로드되지 않으면 페이지를 새로고침합니다.

---

## START LISTENING이 동작하지 않음

- 탭 오디오 소스를 사용 중이라면 **연동** 탭에 OpenAI API 키가 입력되어 있는지 확인합니다.
- 탭 오디오 캡처 권한 요청이 차단되지 않았는지 확인합니다.
- 현재 탭이 YouTube 페이지인지 확인합니다. 탭 오디오 캡처는 지원 대상 페이지에서만 동작합니다.
- Realtime API 및 Transcription API을 사용 도중 일정 시간 이상 발화 인식이 없을 경우 API 연결을 자동으로 끊어지는 부분이 있습니다. 이에 따른 버그 및 오류가 발생되오니 사용을 하지 않을 시에는 중지를 해주시기 바랍니다.(그렇지 않을 경우 동작중이였던 탭을 닫았다가 다시 열어주시기 바랍니다.)

---

## 마이크 인식이 불안정함

- Chrome 마이크 권한을 확인합니다.
- 원본 언어가 `자동`이면 Web Speech API가 브라우저 기본 언어로 인식합니다. 언어를 명시적으로 설정하세요.
- Web Speech API(또는 웹 브라우저의 마이크)는 OS에 설정된 입력의 기본값으로 동작하기에 스테레오 믹스(이하 '스믹')이 아닐 경우 자신의 마이크로 동작합니다.
- 마이크 소스는 OS에 설정된 기본 입력 장치를 따릅니다. 스테레오 믹스가 기본 입력으로 설정된 경우 마이크가 아닌 다른 입력이 잡힐 수 있습니다.

---

## 번역이 표시되지 않음

- 목표 언어가 원본 언어와 같은지 확인합니다. 목표 언어와 원본 언어가 같으면 번역을 건너뛰게 됩니다.
- 선택한 번역 엔진에 필요한 API 키 또는 URL이 **연동** 탭에 입력되어 있는지 확인합니다.
- 번역 엔진을 `Google (자동)`으로 바꿔 동작 여부를 확인합니다.
- Google 기본 엔진도 실패하면 네트워크 상태를 확인합니다.

---

## Realtime 결과가 끊기거나 중복됨

Realtime API의 VAD(음성 감지)와 중간 번역 표시가 조정 중입니다. 안정적인 자막이 필요하면 실시간 탭에서 STT 엔진을 **Whisper (Transcription API)** 로 전환하세요.

---

## 자막이 YouTube 컨트롤 바와 겹침

표시 탭에서 **자막 위치**를 `상단`으로 변경하거나, **글자 크기**를 줄여보세요.
