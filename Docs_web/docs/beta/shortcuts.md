# 단축키

Chrome 전역 단축키는 Chrome 확장 프로그램 단축키 설정 화면에서 관리합니다.

확장 팝업 왼쪽 하단의 `단축키` 버튼을 누르면 다음 페이지가 열립니다.

```text
chrome://extensions/shortcuts
```

향후 전역 단축키는 `manifest.json`의 `commands`로 등록됩니다. 사용자는 Chrome 단축키 설정 화면에서 원하는 키 조합으로 변경할 수 있습니다.

페이지 내부에서만 동작하는 세부 단축키는 별도 기능으로 추가될 수 있습니다.
