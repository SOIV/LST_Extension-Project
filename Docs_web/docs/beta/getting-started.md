# 시작하기

## 설치

베타 배포 방식에 따라 확장 프로그램을 설치합니다. Chrome 웹 스토어 배포 전에는 개발자 모드로 압축 해제된 확장 프로그램을 로드할 수 있습니다.

## 기본 사용 흐름

1. 확장 프로그램을 설치합니다.
2. YouTube 페이지를 엽니다.
3. 확장 팝업을 열고 `연동` 탭에서 필요한 API 키를 입력합니다.
4. `실시간` 탭에서 원본 언어, 번역 언어, STT 엔진을 선택합니다.
5. 상단의 `START LISTENING` 버튼을 눌러 자막을 시작합니다.

## 베타 주의사항

- 탭 오디오 캡처는 Chrome의 권한과 현재 탭 상태에 영향을 받습니다.
- Web Speech API는 브라우저 언어와 마이크 권한의 영향을 받습니다.
- Realtime API는 지연 시간이 낮지만 VAD와 중간 번역 결과가 조정 중입니다.
- API 키는 현재 브라우저의 로컬 저장소에 저장됩니다.
