# 커뮤니티 자막

커뮤니티 자막은 사용자가 직접 만들거나 업로드한 자막을 YouTube 영상 ID 기준으로 공유하는 기능입니다.

---

## 동작 방식

1. 사용자가 영상 URL을 기반으로 자막을 플랫폼에 등록합니다.
2. 플랫폼은 언어, 버전, 설명, 업로더 정보를 함께 저장합니다.
3. 확장 프로그램이 YouTube 영상 페이지에서 영상 ID를 감지합니다.
4. 해당 영상에 자막이 있으면 사용자의 언어 설정에 맞는 자막을 불러옵니다.
5. 자막은 YouTube 기본 자막이 아닌 LST 오버레이로 표시됩니다.

---

## 자막 상태 체계

커뮤니티 자막은 제출 후 다음 단계를 거칩니다.

| 상태 | 설명 |
|---|---|
| **커뮤니티 제출** | 사용자가 업로드한 초기 상태. LST 앱에서 조회 가능. |
| **크리에이터 승인** | 채널 소유자가 확인하고 승인한 자막. LST 앱에서 우선 표시. |
| **YouTube 반영** | 크리에이터가 YouTube 채널에 업로드한 자막. YouTube 공식 자막으로 표시됨. |

:::note
YouTube에 반영되지 않은 자막은 LST 확장 프로그램과 앱에서만 볼 수 있습니다. YouTube 기본 자막 버튼을 통해서는 표시되지 않습니다.
:::

---

## 지원 포맷

| 포맷 | 설명 |
|---|---|
| SRT | 가장 일반적인 타임라인 자막 포맷 |
| VTT | 웹 미리보기와 브라우저 표시에 적합 |
| SMI/SAMI | 한국어 자막에서 자주 사용 |
| TTML | 복잡한 스타일 포함 포맷 |

업로드된 자막은 내부 공통 모델로 변환한 뒤 필요한 포맷으로 다시 제공합니다.

---

## 버전(리비전) 관리

같은 영상과 언어에 대해 여러 자막 버전을 둘 수 있습니다. 수정본을 저장하면 기존 자막을 덮어쓰지 않고 새 리비전으로 기록되어 이전 상태를 추적할 수 있습니다.

---

## 번역 자막 작업

번역 자막을 시작하려면 먼저 해당 영상의 원어 자막이 플랫폼에 존재해야 합니다. 원어 자막은 다음 방식 중 하나로 등록할 수 있습니다.

- 크리에이터가 직접 업로드
- 커뮤니티 사용자가 작성
- AI 자동 생성 초안 (기여자 검토 후 사용)

---

## 번역 팀

각 YouTube 채널은 커뮤니티 기반 번역 팀을 연결할 수 있습니다. 팀은 공개 프로필을 가지며 팀원 목록, 작업 언어, 참여 영상 목록, 기여 내역을 표시합니다.
