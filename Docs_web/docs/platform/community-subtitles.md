# 커뮤니티 자막

커뮤니티 자막은 사용자가 직접 만들거나 업로드한 자막을 영상 ID 기준으로 공유하는 기능입니다.

## 동작 방식

1. 사용자가 영상 URL 또는 videoId를 기준으로 자막을 등록합니다.
2. 플랫폼은 언어, 버전, 설명, 업로더 정보를 함께 저장합니다.
3. 확장 프로그램은 영상 페이지에서 videoId를 감지합니다.
4. 플랫폼에 자막이 있으면 사용자의 언어 설정에 맞는 자막을 불러옵니다.
5. 자막은 YouTube 기본 자막이 아니라 LST 오버레이로 표시됩니다.

## 지원 예정 포맷

- SRT
- VTT
- SMI/SAMI
- TTML
- TXT 기반 초안

업로드된 자막은 내부 공통 모델로 변환한 뒤 필요한 표시 포맷으로 다시 제공합니다.

## 버전 관리

같은 영상과 언어에 대해 여러 자막 버전을 둘 수 있습니다. 새 수정본은 기존 자막을 덮어쓰기보다 새 리비전으로 저장해 이전 상태를 추적할 수 있게 합니다.
