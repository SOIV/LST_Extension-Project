# 자막 포맷

LST는 여러 자막 포맷을 하나의 내부 구조로 정규화한 뒤, 필요한 포맷으로 다시 변환하는 방식을 사용합니다.

## 지원 대상

| 포맷 | 상태 | 설명 |
|---|---|---|
| SRT | 지원 예정 | 가장 일반적인 타임라인 자막 포맷입니다. |
| VTT | 지원 예정 | 웹 미리보기와 브라우저 표시 흐름에 적합합니다. |
| SMI/SAMI | 계획 중 | 언어와 스타일 처리 정책이 필요합니다. |
| TTML | 계획 중 | 복잡한 구조와 스타일이 있어 일부 기능부터 지원합니다. |

## 기본 자막 정보

각 자막 줄은 최소한 다음 정보를 가집니다.

- 시작 시간
- 종료 시간
- 표시 텍스트
- 언어
- 선택적 스타일 또는 위치 정보

## 변환 시 주의사항

포맷을 변환하면 일부 정보가 사라질 수 있습니다. 예를 들어 VTT의 위치 정보나 고급 스타일은 SRT로 변환할 때 보존되지 않을 수 있습니다.

플랫폼은 가능한 경우 변환 중 손실된 정보를 사용자에게 알려주는 방향으로 설계합니다.
