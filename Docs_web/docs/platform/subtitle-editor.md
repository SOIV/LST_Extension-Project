# 자막 편집기

Platform 자막 편집기는 영상 미리보기와 자막 타임라인을 함께 보면서 자막을 수정하는 웹 편집 환경입니다.

## 기본 편집

기본 편집 화면에서는 각 자막 줄의 시작 시간, 종료 시간, 표시 텍스트를 수정합니다.

주요 작업:

- 자막 텍스트 수정
- 시작/종료 시간 조정
- 자막 줄 추가 또는 삭제
- 저장 시 새 리비전 생성

## 미리보기

편집 화면에서는 YouTube 영상 미리보기를 함께 제공하는 방향으로 설계합니다. 사용자는 실제 시청 환경과 가까운 상태에서 자막 위치와 표시 타이밍을 확인할 수 있습니다.

## 고급 편집

고급 사용자를 위한 스크립트 기반 편집은 실험 기능으로 검토합니다. 조건부 표시, 스타일 제어, 화자 구분 같은 기능은 v1.0.0 이후 단계적으로 정리합니다.
