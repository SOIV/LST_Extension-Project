# 자막 편집기

Platform 자막 편집기는 YouTube 영상 미리보기와 자막 타임라인을 함께 보면서 자막을 수정하는 웹 편집 환경입니다.

---

## 영상 미리보기

편집 화면에서는 YouTube 영상을 직접 재생하면서 자막 타이밍을 확인할 수 있습니다.

- 재생 / 일시정지 / 구간 이동
- 재생 속도 조절
- LST 서버에 저장된 자막이 영상 위에 오버레이로 표시되어, 실제 시청 환경과 가까운 상태에서 확인 가능

---

## 편집 뷰

### Timeline View (기본)

대부분의 자막 작업에 적합한 기본 편집 방식입니다.

각 자막 줄에 대해 다음을 수정합니다.

- 시작 시간
- 종료 시간
- 표시 텍스트

주요 작업:

- 자막 텍스트 수정
- 시작/종료 시간 조정
- 자막 줄 추가 또는 삭제
- 저장 시 새 리비전 생성

### Scripting View (고급, 실험적)

고급 사용자를 위한 스크립트 기반 편집 방식입니다. 조건부 표시, 스타일 제어, 화자 구분 같은 표현이 필요한 경우 사용합니다.

내부적으로 Timeline View와 동일한 자막 데이터를 사용하므로, 두 뷰 간 전환이 가능합니다.

:::note
Scripting View는 초기에 실험(Beta) 기능으로 제공될 수 있습니다.
:::

---

## 리비전 관리

편집 내용을 저장하면 기존 자막을 덮어쓰지 않고 새 리비전으로 저장됩니다.

- 리비전 목록에서 이전 버전과 비교할 수 있습니다.
- 특정 리비전을 현재 버전으로 고정(pin)할 수 있습니다.
- 잘못된 수정이 있어도 이전 상태로 복원할 수 있습니다.
