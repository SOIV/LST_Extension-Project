# Platform 개요

LST Platform은 커뮤니티 자막을 만들고, 관리하고, 영상에서 사용할 수 있도록 제공하는 웹 플랫폼입니다.

확장 프로그램과 데스크탑 앱은 플랫폼에 저장된 자막을 조회해 사용자 화면에 표시할 수 있습니다. 사용자는 플랫폼에서 자막을 업로드하거나 편집하고, 영상과 언어에 맞는 자막을 관리할 수 있습니다.

## 주요 기능

- 영상 URL 또는 videoId 기반 자막 조회
- 커뮤니티 자막 업로드와 버전 관리
- 자막 편집기와 미리보기
- 크리에이터 승인 흐름
- 자막 포맷 변환과 손실 정보 안내

## v1.0.0 기준

Platform 문서는 v1.0.0 준비를 위해 미리 작성한 사용자 문서 스냅샷입니다. 실제 화면과 정책이 확정되면 스크린샷과 세부 절차를 추가합니다.
