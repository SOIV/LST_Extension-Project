# API 키 설정

확장 팝업의 `연동` 탭에서 API 키를 입력합니다. API 키는 브라우저 로컬 저장소에 저장되며 Chrome 동기화 저장소에는 저장하지 않습니다.

## OpenAI

OpenAI 키는 탭 오디오 기반 STT와 Realtime STT에 사용됩니다.

필요한 경우:

- OpenAI Transcription API
- OpenAI Realtime API

## DeepL

DeepL API 키는 DeepL 번역 엔진을 사용할 때 필요합니다.

DeepL Free 키와 Pro 키는 API 엔드포인트가 다를 수 있으며, 확장 프로그램은 키 형태에 따라 적절한 엔드포인트를 선택합니다.

## Papago

Papago는 Naver Cloud Platform에서 발급한 Client ID와 Client Secret이 필요합니다.

## Google Translate

기본 Google Translate 엔진은 별도 API 키 없이 사용할 수 있습니다.

Google Apps Script 방식은 사용자가 직접 배포한 Apps Script 웹 앱 URL이 필요합니다.
