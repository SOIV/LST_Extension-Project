# 기능 상태

| 기능 | 상태 | 메모 |
|---|---|---|
| 커뮤니티 자막 표시 | ✅ 사용 가능 | YouTube 플레이어 오버레이 |
| 자막 언어 선택 | ✅ 사용 가능 | 플레이어 패널 또는 팝업 |
| 배지 상태 표시 | ✅ 사용 가능 | CC(자막 있음) / STT(녹음 중) |
| 탭 오디오 STT (Whisper) | ✅ 사용 가능 | OpenAI API 키 필요 |
| 탭 오디오 STT (Realtime) | ⚠️ 조정 중 | VAD·중간 번역 세부 조정 필요 |
| 마이크 STT (Web Speech API) | ✅ 사용 가능 | 언어 자동 감지 미지원 |
| 번역 - Google Translate | ✅ 사용 가능 | 기본 엔진, 키 불필요 |
| 번역 - Google Apps Script | ✅ 사용 가능 | Apps Script 배포 URL 필요 |
| 번역 - Naver Papago | ✅ 사용 가능 | NCP Client ID + Secret 필요 |
| 번역 - DeepL | ✅ 사용 가능 | DeepL API 키 필요, Free 500k자/월 |
| 중간 번역 (Interim) | ✅ 사용 가능 | 기본 off, 실시간 탭에서 활성화 |
| 자막 표시 설정 | ✅ 사용 가능 | 글꼴·색상·크기·투명도·테두리 등 |
| 표시 모드 (split/focus) | ✅ 사용 가능 | 원문+번역 분리 또는 번역만 표시 |
| 번역 캐시 | ✅ 사용 가능 | 표시 탭에서 토글 |
| 데스크탑 앱 연동 | 🔜 계획 중 | v1.0.0 이후 |
| API 사용량 표시 | 🔜 예정 | DeepL·OpenAI 우선 검토 |
| Twitch / CHZZK / SOOP 지원 | 🔜 계획 중 | YouTube 이후 |
| OBS 스트리밍 오버레이 | 🔜 계획 중 | |
