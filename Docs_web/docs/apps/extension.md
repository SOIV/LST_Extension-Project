# Chrome 확장 프로그램

LST Chrome 확장 프로그램은 YouTube 페이지 위에 커뮤니티 자막 또는 실시간 STT/번역 자막을 오버레이로 표시합니다.

## 설치

Chrome 웹 스토어 배포 전에는 개발자 모드로 압축 해제된 확장 프로그램을 로드합니다.

---

## 팝업 탭 구성

확장 아이콘을 클릭하면 팝업이 열립니다. 팝업은 다음 6개 탭으로 구성됩니다.

| 탭 | 역할 |
|---|---|
| **커뮤니티** | 커뮤니티 자막 on/off, 언어 선택, 현재 영상 자막 상태 확인 |
| **실시간** | STT 오디오 소스·엔진·모델, 번역 엔진, 언어 설정 |
| **표시** | 글꼴·색상·크기·투명도 등 자막 외형 설정 |
| **연동** | API 키 입력 (OpenAI, DeepL, Papago, Google Apps Script) |
| **상태** | Web Speech 지원 여부, OpenAI 키 등록 여부, STT 실행 상태 확인 |
| **정보** | 버전, 라이선스 등 |

---

## 배지 상태

확장 아이콘에 표시되는 배지로 현재 상태를 확인할 수 있습니다.

| 배지 | 색상 | 의미 |
|---|---|---|
| `CC` | 초록 | 현재 영상에 커뮤니티 자막 있음 |
| `STT` | 빨간색 | 실시간 STT 녹음 중 |
| `…` | 회색 | 자막 확인 중 |
| (없음) | 회색 | 자막 없음 또는 YouTube 페이지가 아님 |

---

## 커뮤니티 자막 사용

1. YouTube 영상 페이지를 엽니다.
2. 배지가 `CC`(초록)이면 해당 영상에 커뮤니티 자막이 있습니다.
3. 팝업 **커뮤니티** 탭에서 자막을 켜고 언어를 선택합니다.
4. 자막은 YouTube 기본 자막이 아닌 LST 오버레이로 표시됩니다.

API 키 없이 바로 사용할 수 있습니다.

---

## 실시간 STT 사용

### 오디오 소스 선택

실시간 탭의 **오디오 소스**에서 두 가지 방식 중 하나를 선택합니다.

| 소스 | 설명 | STT 엔진 |
|---|---|---|
| 탭 오디오 | 현재 탭에서 재생 중인 방송 소리를 직접 캡처 | OpenAI Whisper 또는 Realtime (키 필요) |
| 마이크 | 마이크 입력 사용 | Web Speech API (키 불필요) |

### 시작 방법

1. 실시간 탭에서 오디오 소스, STT 엔진, 원본 언어, 번역 언어를 설정합니다.
2. 탭 오디오를 사용한다면 **연동** 탭에서 OpenAI API 키를 먼저 입력합니다.
3. 팝업 상단의 **START LISTENING** 버튼을 누릅니다.
4. 배지가 `STT`(빨간색)으로 바뀌면 녹음 중 상태입니다.
5. 중지하려면 **STOP LISTENING**을 누릅니다.

---

## 자막 표시 모드

표시 탭의 **표시 모드**에서 자막 레이아웃을 선택합니다.

| 모드 | 설명 |
|---|---|
| **분리 (split)** | 원문과 번역을 위아래로 나눠 표시 (기본값) |
| **집중 (focus)** | 번역된 자막만 표시 |

---

## 자막 외형 설정

표시 탭에서 다음 설정을 조정할 수 있습니다.

- 글꼴 모음, 색상, 불투명도
- 글자 크기 (50~400%)
- 테두리 스타일 (없음 / 양각 / 음각 / 균일 / 드롭 새도우)
- 배경 색상과 불투명도
- 창 색상과 불투명도

**기본값으로 재설정** 버튼으로 초기화할 수 있습니다.

---

## 사용 시 주의사항

- 탭 오디오 캡처는 Chrome의 권한 상태와 현재 탭 조건에 영향을 받습니다.
- 마이크(Web Speech API) 모드에서 원본 언어를 **자동**으로 설정하면 인식이 불안정해질 수 있습니다. 언어를 명시적으로 지정하세요.
- Realtime API는 지연 시간이 낮지만 VAD와 중간 번역 표시가 조정 중입니다.
- API 키는 브라우저 로컬 저장소에 저장됩니다. 공용 기기에서는 사용 후 키를 삭제하세요.
