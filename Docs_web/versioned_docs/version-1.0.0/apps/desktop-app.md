# 데스크탑 앱

LST 데스크탑 앱은 확장 프로그램의 한계를 보완하고, 더 안정적인 오디오 캡처와 로컬 STT/번역 처리를 제공하는 실행 앱입니다.

## 역할

- 시스템 오디오를 더 안정적으로 캡처합니다.
- 로컬 또는 고성능 STT 엔진을 사용할 수 있습니다.
- 브라우저 밖에서 실행해야 하는 STT, 번역, 로컬 AI 처리를 담당합니다.
- 필요하면 확장 프로그램과 로컬 연결로 결과를 전달합니다.

## 앱 유형

| 유형 | 목적 | 설명 |
|---|---|---|
| Lite Helper | 확장 프로그램 보조 | 실시간 시청 중 오디오 캡처와 STT 처리를 보조합니다. |
| Full Desktop App | 독립 실행 환경 | 실시간 STT/번역, 로컬 AI 처리, 장치 설정, 확장 프로그램 연동을 더 세밀하게 관리합니다. |

## 확장 프로그램과의 연동

데스크탑 앱은 로컬 연결을 통해 STT 또는 번역 결과를 확장 프로그램으로 전달할 수 있습니다. 사용자는 브라우저에서 영상을 보면서 데스크탑 앱의 처리 결과를 오버레이 자막으로 확인할 수 있습니다.

## 준비 상태

데스크탑 앱 문서는 v1.0.0 기능 확정에 맞춰 계속 보강됩니다. 준비 단계에서는 확장 프로그램 단독 사용 흐름을 우선 권장합니다.
