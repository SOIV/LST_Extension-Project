# Chrome 확장 프로그램

LST Chrome 확장 프로그램은 브라우저 페이지 위에 실시간 자막과 번역을 표시합니다. 커뮤니티 자막이 있는 영상에서는 플랫폼에서 자막을 불러와 표시하고, 자막이 없는 경우 STT 엔진을 통해 실시간 자막을 생성할 수 있습니다.

## 설치

배포 방식에 따라 확장 프로그램을 설치합니다. Chrome 웹 스토어 배포 전에는 개발자 모드로 압축 해제된 확장 프로그램을 로드할 수 있습니다.

## 기본 사용 흐름

1. 확장 프로그램을 설치합니다.
2. YouTube 페이지를 엽니다.
3. 확장 팝업을 열고 `연동` 탭에서 필요한 API 키를 입력합니다.
4. `실시간` 탭에서 원본 언어, 번역 언어, STT 엔진을 선택합니다.
5. 상단의 `START LISTENING` 버튼을 눌러 자막을 시작합니다.

## 커뮤니티 자막

커뮤니티 자막이 제공되는 영상에서는 영상 ID를 기준으로 플랫폼 자막을 조회합니다. 사용자는 언어를 선택하고, 확장 프로그램의 오버레이를 통해 YouTube 플레이어 위에서 자막을 볼 수 있습니다.

## 사용 시 주의사항

- 탭 오디오 캡처는 Chrome 권한과 현재 탭 상태에 영향을 받습니다.
- Web Speech API는 브라우저 언어, 마이크 권한, OS 입력 장치 설정의 영향을 받습니다.
- Realtime API는 지연 시간이 낮지만 VAD와 중간 번역 표시가 조정 중입니다.
- API 키는 현재 브라우저의 로컬 저장소에 저장됩니다.
