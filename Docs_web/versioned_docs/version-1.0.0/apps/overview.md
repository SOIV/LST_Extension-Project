# Apps 개요

Apps 문서는 LST Chrome 확장 프로그램과 데스크탑 앱을 함께 다룹니다.

확장 프로그램은 YouTube 같은 웹 페이지 위에서 커뮤니티 자막 또는 실시간 STT/번역 자막을 표시하는 기본 사용자 도구입니다. 데스크탑 앱은 확장 프로그램만으로 처리하기 어려운 오디오 캡처, 로컬 STT, 번역, 로컬 AI 실행을 보조하는 앱입니다.

## 구성

- Chrome 확장 프로그램: 브라우저에서 자막 표시, 실시간 STT, 번역, 커뮤니티 자막 조회를 담당합니다.
- 데스크탑 앱: 안정적인 시스템 오디오 캡처, 로컬 STT/번역 처리, 로컬 AI 실행, 확장 프로그램 연동을 담당합니다.
- 공통 설정: API 키, STT 엔진, 번역 엔진, 단축키, 문제 해결을 포함합니다.

## v1.0.0 기준

이 문서는 v1.0.0 사용자 문서 스냅샷입니다. 확장 프로그램 사용 흐름을 우선 설명하며, 데스크탑 앱 문서는 기능 확정에 맞춰 계속 보강됩니다.
