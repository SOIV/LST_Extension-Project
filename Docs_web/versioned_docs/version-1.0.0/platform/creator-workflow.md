# 크리에이터 승인 흐름

크리에이터 승인 흐름은 커뮤니티가 만든 자막을 채널 소유자가 확인하고 승인할 수 있게 하는 기능입니다.

## 기본 흐름

1. 사용자가 영상에 대한 자막을 업로드합니다.
2. 자막은 플랫폼에 저장되고, 승인 전 상태로 관리됩니다.
3. 크리에이터는 미리보기 화면에서 자막을 확인합니다.
4. 문제가 없으면 승인하고, 수정이 필요하면 거절하거나 피드백을 남깁니다.
5. 승인된 자막은 LST 앱에서 우선 표시될 수 있습니다.

## 승인 전 자막 표시

승인되지 않은 자막은 YouTube 채널에 직접 반영되지 않습니다. 대신 LST 확장 프로그램과 데스크탑 앱에서 커뮤니티 자막으로 표시할 수 있습니다.

이 구조는 커뮤니티 번역을 가능하게 하면서도 채널 소유자의 권한과 영상 플랫폼 정책을 보호하기 위한 방식입니다.
