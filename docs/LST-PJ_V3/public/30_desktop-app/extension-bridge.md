# Desktop App Extension Bridge

Status: planned

Desktop App과 Chrome Extension의 연동 방식을 다룬다.

## Scope

- WebSocket 또는 로컬 브릿지
- Lite Helper 또는 Full Desktop App의 STT/번역 결과 전달
- Desktop AI runtime의 프리셋 기반 번역 결과 전달
- Extension 오버레이 표시 연동
- 연결 실패 시 fallback 정책
