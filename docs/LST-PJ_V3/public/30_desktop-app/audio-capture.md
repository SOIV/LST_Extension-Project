# Desktop App Audio Capture

Status: planned

Desktop App의 시스템 오디오 캡처 기능을 다룬다.

## Scope

- Windows WASAPI Loopback
- macOS CoreAudio
- 입력 장치 선택
- 캡처된 오디오를 Desktop STT runtime 또는 Extension bridge로 전달
