# Platform Subtitle Editor

Status: in_progress

웹 플랫폼의 자막 편집기, 리비전, 저장 흐름을 다룬다.

## Scope

- YouTube IFrame 미리보기
- Timeline View
- Scripting View
- SRT/VTT 편집 및 저장
- 리비전 생성
- 현재 리비전 고정

## Planned

- 미리보기 영상 크기 조정 UX
- SMI/SAMI, TTML 편집 지원 구체화
- 리비전/롤백 정책 문서화
