# Extension Community Subtitles

Status: active

Chrome Extension에서 커뮤니티 자막을 조회하고 YouTube 플레이어 위에 표시하는 기능을 다룬다.

## Scope

- YouTube videoId 감지
- 플랫폼 자막 API 조회
- 사용자 언어 우선순위 적용
- 자체 오버레이 렌더러로 자막 표시
- YouTube SPA 이동 시 자막 재로드
- 배지/토글/언어 선택 UX
