## 6. 사용자 여정별 UX

### 신규 사용자
```
1. 첫 설치
   → 자동으로 Web Speech 선택됨
   → "업그레이드하시겠습니까?" 배너

2. 설정 진입
   → "Whisper 무료 체험 (60분)" 강조
   → 원클릭으로 전환

3. 60분 소진
   → "이번 달 무료 시간 소진"
   → "Web Speech로 자동 전환됨"
   → "Pro 구독 또는 API 키 등록"
```

### 고급 사용자
```
1. 설정 진입
   → "고급 모드" 켜기

2. 옵션 선택
   → 내 OpenAI 키 입력
   → 또는 커스텀 엔드포인트

3. 로드 밸런싱 설정
   → 우선순위 지정
   → 자동 Fallback
```

## 7. 설정 저장 데이터 구조

```javascript
{
  "stt": {
    // 현재 선택된 엔진
    "engine": "whisper", // "webspeech" | "whisper" | "custom"
    
    // Whisper 설정
    "whisper": {
      // 제공 방식
      "mode": "server", // "server" | "own_api" | "custom"
      
      // 서버 제공 모드
      "server": {
        "plan": "free", // "free" | "pro"
        "used_minutes": 18,
        "quota_minutes": 60,
        "reset_date": "2025-01-01"
      },
      
      // 사용자 API 모드
      "own_api": {
        "provider": "openai", // "openai" | "huggingface"
        "api_key": "sk-xxx (encrypted)",
        "endpoint": "https://api.openai.com/v1/audio/transcriptions"
      },
      
      // 커스텀 엔드포인트
      "custom": {
        "endpoint": "https://...",
        "auth_type": "bearer",
        "auth_key": "xxx (encrypted)",
        "request_format": "json",
        "response_path": "result.text"
      }
    },
    
    // Web Speech 설정
    "webspeech": {
      "lang": "ja-JP",
      "continuous": true,
      "interim_results": true
    },
    
    // 고급 설정
    "advanced": {
      "mode": "simple", // "simple" | "advanced"
      "auto_fallback": true,
      "priority_order": ["whisper_server", "whisper_own", "webspeech"]
    }
  }
}
```

## 9. 최종 결론

**추천 방식: 카드 + 펼침/접기**

장점:
- ✅ 시각적으로 깔끔
- ✅ 선택이 직관적
- ✅ 초보자도 쉽게 이해
- ✅ 고급 설정은 펼쳐서 접근
- ✅ 데스크톱 화면에 최적화

구현:
- 기본: 4개 카드 (Web Speech, Whisper 서버, Whisper 내 API, 기타)
- 선택 시: 해당 카드 강조 + 하단에 상세 설정 표시
- 간단 모드 / 고급 모드 토글 제공

이렇게 하면 복잡해 보이지 않으면서도 모든 옵션을 제공할 수 있습니다!
