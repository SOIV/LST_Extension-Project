# 자막 커뮤니티 플랫폼 언어 시험·검수자 설계 정리

## 1. 설계 목적
- 자격증 중심이 아닌 **실무 능력 중심** 평가
- 팬 번역러와 실무 경험자를 모두 포용
- 경쟁/서열화 방지, 신뢰 보조 지표 제공
- 법적·운영 리스크를 최소화한 온라인 시험 구조

---

## 2. 사용자 프로필 내 언어 정보

### 2.1 언어 자격증 표시
- 선택 사항
- 점수 미표시
- 공식 등급만 표시 (예: JLPT N1/N2/N3)
- 의미:
  - 해당 언어를 **체계적으로 학습했음**을 나타내는 보조 지표

### 2.2 포트폴리오 등록
- 외부 번역 작업, 프로젝트 참여 이력 등록 가능
- 공개 범위 선택:
  - 전체 공개 / 커뮤니티 공개 / 비공개(운영진 확인)
- 자격증이 없는 실무 고수 보호 목적

---

## 3. 간편 확인 시험 개요

### 3.1 시험 성격
- 공식 자격증 대체 ❌
- 실무 감각 및 이해도 **자기 확인 + 플랫폼 참고용**
- 점수/랭킹 공개 없음

### 3.2 응시 규칙
- 언제든 응시 가능
- 제한: **2주 1회 또는 월 2회**
- 시험 결과에는 다음만 표시:
  - 시험 응시 날짜
  - 읽기/듣기/쓰기 가능 여부(상태)

---

## 4. 시험 구성

### 4.1 필수 시험
- 총 10문제
- 읽기 5문제 + 듣기 5문제
- 문제 유형:
  - 문법 문제 ❌
  - 문맥 이해, 의미 판단 중심

### 4.2 문제 출제 방식
- 공식 시험 **기출 유형 참고**
- 실제 기출 문제 사용 ❌
- 문제 풀(pool) 기반
- **월 1회 무작위 교체**

---

## 5. 쓰기 시험 (선택)

### 5.1 응시 방식
- 시험 시작 전 선택
- 선택 시 시험 시간 +10분

### 5.2 문제 구성 (총 2문제)

#### 문제 1: 듣고 쓰기
- 낮은 난이도의 일본어 음성 청취
- 의미 전달 중심 요약 작성
- 받아쓰기 아님

#### 문제 2: 번역 작성 (A안)
- **KR → JP 번역**
- 중문 길이 (3~5문장)
- 상황/톤 제시

### 5.3 말하기 시험
- 완전 제외
- 시험 항목으로 다루지 않음

---

## 6. 번역기 사용 억제 정책

> 완전 차단이 아닌 **사용 억제 + 판별 보조** 목적

적용 사항:
- 붙여넣기(Ctrl+V) 차단
- 일정 시간 미만 제출 불가
- 한 번에 대량 텍스트 입력 시 입력 무효
- 타이핑 패턴 로그 (참고용 플래그)

※ 화면 감시, 실시간 화면 확인 시스템은 **법적 문제로 제외**

---

## 7. 시험 결과 처리 방식

- 점수 ❌
- 등급 ❌
- 공개 프로필 노출 ❌

활용 범위:
- 검수 참여 가능 여부 판단
- 공식 검수자 심사 참고
- 분쟁 발생 시 내부 참고 자료

---

## 8. 검수자 구조

### 8.1 공식 검수자
- 언어 자격증 보유
- 플랫폼 공식 인증
- 최종 검수 및 승인 권한
- 스타일 가이드 결정
- 분쟁 판단 책임

### 8.2 검수 참여자
- 공식 인증 ❌
- 언어 자격증 **또는** 간편 확인 시험 통과
- 포트폴리오 보유 시 우대
- 검수 보조, 리뷰 참여 가능
- 최종 결정 권한 없음

---

## 9. 플랫폼 철학 요약

> 자격증은 참고 정보일 뿐,
> **실제 번역 실력은 활동과 결과로 증명된다.**

- 실력은 열어두고
- 책임은 단계적으로 부여하는 구조

---

## 10. 추후 확장 가능 항목
- 시험 문제 유형 세분화
- 검수자 권한 단계 추가
- 크리에이터/출판 연계 기능
- 언어별 시험 구조 확장
